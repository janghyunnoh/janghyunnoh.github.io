# CV sources

Built with [Awesome-CV](https://github.com/posquit0/Awesome-CV) (CC BY-SA 4.0) and XeLaTeX.

```bash
xelatex cv_en.tex   # -> cv_en.pdf  (copy to ../assets/cv/Janghyun_Noh_CV.pdf)
xelatex cv_ko.tex   # -> cv_ko.pdf  (copy to ../assets/cv/Janghyun_Noh_CV_KO.pdf)
```

Fonts needed: Source Sans 3, Roboto, Font Awesome 6 (Free + Brands), Noto Sans CJK KR.
`fontawesome6.sty` here is a small local shim that maps the header icons to the Font Awesome 6 OTF fonts.
